# Changelog

All notable changes to Clash Tracker are listed here. Versions follow
[Semantic Versioning](https://semver.org/). Each release on GitHub takes its notes from the
matching section below.

## [1.1.0] - 2026-11-26

Clash Tracker now installs its own updates, and you can move and resize the overlay.

- Ctrl+R now works while Clash of Clans is the window in front, including in Google Play Games.
- Google Play Games is found automatically, whatever your player name is.
- The section tabs on the overlay (Overview, Rushed, Laboratory and the rest) work again.
- Drag the overlay to move it, and drag a corner to resize it. Settings → Overlay can reset it.
- New versions are checked each time Clash Tracker starts and when you press Check now, and install by themselves. You can turn this off in Settings → Data and updates.
- No more pop-up notifications. Messages show in the tray menu instead.
- Removed the demo preview, the About page and the notice on the setup screen.

**Install:** download `ClashOverlay-Setup-1.1.0.exe` and run it. Version 1.0.0 cannot update itself, so install this one by hand; later versions install on their own. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

## [1.0.0] - 2026-11-26

The first release of Clash Tracker: press **Ctrl+R** over Clash of Clans to see how close your village is to max.

- Upgrade progress, rushed items, builder and lab upgrades, heroes, pets, equipment, clan and war.
- Main Village and Builder Base, for as many accounts as you like.
- Uses your own Clash of Clans API key and the game's village export.

**Install:** download `ClashOverlay-Setup-1.0.0.exe` and run it, or use the portable zip. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
