# Changelog

All notable changes to Clash Tracker are listed here. Versions follow
[Semantic Versioning](https://semver.org/). Each release on GitHub takes its notes from the
matching section below.

## [1.0.0] - 2026-11-26

The first release of Clash Tracker: press **Ctrl+R** over Clash of Clans to see how close your village is to max.

- Upgrade progress, rushed items, builder and lab upgrades, heroes, pets, equipment, clan and war.
- Main Village and Builder Base, for as many accounts as you like.
- Uses your own Clash of Clans API key and the game's village export.

**Install:** download `ClashOverlay-Setup-1.0.0.exe` and run it, or use the portable zip. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
